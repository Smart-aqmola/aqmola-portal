# Логотип: варианты для выбора

Свои знаки в цветах портала, без герба и госсимволики. Выбор за руководством, на сайт пока не встроены.

- `aqmola-logo-variants.png` — все три варианта одной картинкой (для пересылки).
- `overview.html`, `../logo-variants.html` — те же варианты в браузере (в шапке, во вкладке, иконка приложения).
- Отдельные файлы SVG (растягиваются без потери качества): знак, знак для тёмного фона, знак с надписью.
  - A. Горы и солнце — `a-mountains*.svg`
  - B. Дом-капля — `b-house-drop*.svg`
  - C. Орнамент — `c-ornament*.svg`

Цвета: бирюзовый `#1C7C9C`, тёмный `#10242E`, солнце `#E9B23C`, белый.
