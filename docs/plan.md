# План: тестовый фронт портала Aqmola

Статус: первая версия (этапы 1–10) выполнена. Добавлена вторая часть по техническому заданию (этапы 11–19, 2026-10-21). План уточнён по исследованию astana.kz ([docs/research/astana-kz.md](research/astana-kz.md)). Основа дизайна — `design/variants/1-panorama.html`.

Решения после исследования (2026-10-20):

- Афишу мероприятий в первую версию **не берём**.
- Опросы и 3D-туры — **после первой версии** (раздел «Позже» внизу).
- Тёмная тема и режим для слабовидящих — в **этап 10**.
- Услуги для жителей и бизнеса **разделяем переключателем** «Жителям / Бизнесу» (параметр адреса `for=resident|business`, по умолчанию «Жителям»).

Решения от 2026-10-21 (по техническому заданию):

- **Английский язык отставлен.** Новый английский текст не пишем, в переключателе языка его не показываем. Словарь `en.json` и его тесты пока не удаляем, чтобы не ломать сборку; полное удаление — отдельным решением.
- **Делаем только фронт.** Бэкенд скоро начнёт писать. Все данные идут через репозитории-заглушки; в этапе 11 фиксируем контракт для бэкендера: сущности, поля, статусы, маршруты.
- **Интеграции — заглушки с пометкой.** ЭЦП, вход через гос. механизмы, SMS, платёжный шлюз, проверка ИИН, справочник адресов, выгрузка XLSX/CSV от сервера: в интерфейсе есть кнопка или экран, данные тестовые, рядом пометка «демо». Реальных вызовов нет.

## Цель первой версии

Рабочий фронт на тестовых данных: все пользовательские сценарии портала для жителей, бизнеса и операторов, три языка, телефон и десктоп. Без сервера и базы: данные отдаёт слой-заглушка, который позже заменяется на API без переписывания страниц.

## Структура

```
src/
  app/[lang]/                 # страницы
    page.tsx                  # главная (Панорама)
    services/                 # каталог, фильтры, поиск
    services/[slug]/          # карточка услуги
    services/[slug]/apply/    # демозаявка
    situations/[slug]/        # жизненная ситуация
    applications/             # мои заявки
    applications/[id]/        # заявка, статус, история
    operator/                 # кабинет оператора (демо)
    news/, news/[slug]/       # новости
    tourism/, tourism/[slug]/ # места
    about/                    # о регионе и о проекте
  features/
    catalog/                  # услуги, ситуации, организации, территории
    applications/             # заявки, статусы, история
    content/                  # новости, места, «скоро»
    each: domain/ (типы, правила) · data/ (репозиторий: интерфейс + заглушка) · ui/ (компоненты)
  shared/
    ui/                       # шапка, подвал, кнопки, карточки, иконки
    i18n/                     # словари ru.json, kk.json, en.json, выбор языка
    styles/                   # токены, базовые стили
tests/e2e/                    # Playwright
```

Правило зависимостей: `ui` → `domain` ← `data`. Страницы получают данные только через репозитории.

- Тексты только через словари ru/kk. Казахский — черновик, вычитка отложена, как и раньше.
- После каждого этапа: `pnpm check`, `pnpm test:e2e`, просмотр на 375 и 1280 px.

## Риски и ограничения

- Казахский и английский тексты потребуют вычитки.
- Фото с Wikimedia (CC BY-SA) годятся для теста; для запуска нужны свои или лицензированные.
- Демозаявки в `localStorage` видны только в одном браузере; общая база появится с backend.
- Списки районов и организаций — тестовые, перед запуском сверить с официальными.
