# Проверка безопасности фронта

Дата: 2026-10-22. Что проверено, что найдено и что остаётся серверу. Фронт без бэкенда — не защита: всё, что ниже помечено «сервер», обязано повторяться на сервере.

## Проверено и в порядке

| Что                                      | Как                                                  | Результат                                                                                                        |
| ---------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Открытый редирект после входа (`?next=`) | `applications/domain/next-path.ts` и тесты           | Принимается только путь внутри сайта и того же языка; `//чужой-сайт`, `\`, управляющие символы отбрасываются     |
| Вставка HTML (XSS)                       | поиск `dangerouslySetInnerHTML`, `innerHTML`, `eval` | Одна вставка — собственный скрипт темы без пользовательских данных. Всё остальное выводит React с экранированием |
| Загрузка файлов                          | `shared/lib/upload-rules.ts`                         | Все формы идут через `checkFile`: pdf, jpg, png, до 5 МБ, до 5 файлов. Содержимое файлов на фронте не читается   |
| Испорченные данные в браузере            | `shared/lib/stored-data-robustness.test.ts`          | 15 парсеров `localStorage` не падают на мусоре, огромных строках и `__proto__`                                   |
| Переполнение хранилища                   | `shared/lib/local-store.ts`                          | Запись не роняет страницу, данные остаются в памяти до перезагрузки                                              |
| Подмена роли в сессии                    | `applications/domain/storage.ts` (`parseSession`)    | Сессия с выдуманной ролью, организацией или именем отбрасывается                                                 |
| Секреты                                  | поиск по файлам и всей истории git                   | Ключей, паролей и `.env` нет                                                                                     |
| Зависимости                              | `pnpm audit --prod`                                  | Уязвимостей нет                                                                                                  |
| Ссылки наружу                            | поиск `target="_blank"`                              | Новых окон без `noopener` нет                                                                                    |

## Исправлено

- **CSV-инъекция в отчётах.** Ячейка, начинающаяся с `=`, `+`, `-`, `@`, получает апостроф, и Excel не выполняет её как формулу (`admin/domain/reports.ts`, `toCsv`). Отрицательные числа не трогаются.
- **CSP ужесточена** (`next.config.ts`). Скрипты, стили, картинки, шрифты и запросы — только со своего адреса (`default-src 'self'`, `connect-src 'self'`); `unsafe-eval` только в `next dev`. Тест `security-headers.spec.ts` проверяет заголовки и то, что страницы ничего не блокируют.

## Осталось осознанно

- **Встроенные скрипты разрешены** (`'unsafe-inline'`). Next.js вставляет данные страницы встроенными скриптами; убрать это можно только одноразовой меткой (nonce) на каждый запрос, а она делает статические страницы динамическими. Делать вместе с бэкендом.
- **HSTS** (браузер ходит только по https) ставит хостинг, не приложение.

## Задачи сервера

Права и выборки по организации; повтор всех проверок форм, файлов (тип по содержимому, антивирус), показаний и платежей; ограничение частоты запросов (особенно код из SMS); сессии в `HttpOnly`-cookie, а не в `localStorage`; подписанные короткие ссылки на файлы; журнал. Подробно — [backend-handoff.md](backend-handoff.md), раздел 7.
