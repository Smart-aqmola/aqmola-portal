# Скорость и объём кода: замеры

Замер: `pnpm build && pnpm start -p 3200`, затем `pnpm perf`. Профиль — телефон 375 px, сеть около «Fast 3G», процессор в 4 раза медленнее. Числа — сжатый трафик первой загрузки страницы.

LCP — когда видно главное содержимое; CLS — насколько прыгает вёрстка (хорошо < 0,1).

Что сделано:

- **Словарь в браузер — только нужными разделами** (`shared/i18n/pick-dictionary.ts`). Раньше шапка и страницы кабинетов получали весь словарь (150 КБ, сжато 32 КБ), и он попадал в каждую страницу. Какие разделы нужны компоненту, проверяет TypeScript.
- **Шапка снова в готовом HTML.** Хук уведомлений читал текущее время при отрисовке, и Next.js откладывал всю шапку до загрузки JS. Теперь время читается только для вошедшего человека.
- **Подвал не прыгает:** основная область занимает не меньше экрана (`globals.css`). Форма входа по телефону рисуется сразу, а не после чтения данных браузера.

Что не стали делать и почему:

- JS около 180 КБ — это React и Next.js; собственный код страницы добавляет 5–15 КБ, откладывать его загрузку почти бесполезно.
- Шрифт: четыре набора символов (около 90 КБ) нужны все — казахские буквы в `cyrillic-ext`, знак тенге ₸ в `latin-ext`.
