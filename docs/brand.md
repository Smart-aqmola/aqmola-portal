# Фирменный стиль Aqmola

Утверждён знак **«Дом-капля»** (вариант B из [design/logo](../design/logo/README.md)): буква «A» в виде крыши дома, внутри капля — портал коммунальных услуг для жилья. Свой знак, без герба и госсимволики.

## Знак и где он лежит

| Что                       | Файл                                        |
| ------------------------- | ------------------------------------------- |
| Знак в шапке сайта        | `src/shared/ui/site-header/site-header.tsx` |
| Иконка вкладки            | `src/app/icon.svg`, `src/app/favicon.ico`   |
| Иконка на экране телефона | `src/app/apple-icon.png` (180×180)          |
| Исходники (SVG)           | `design/logo/b-house-drop*.svg`             |

Правила:

- Знак не перекрашивать, не поворачивать и не растягивать. Вокруг — свободное поле не меньше четверти ширины знака.
- На тёмном фоне — версия `b-house-drop-on-dark.svg` (белая плашка, тёмная «A»).
- Минимальный размер — 16 px (иконка вкладки); рядом с надписью «Aqmola» — от 24 px.
- Надпись «Aqmola» — шрифт Onest, жирность 600.

## Цвета

Палитра «Бурабай» (2026-10-29): сосновый зелёно-бирюзовый и тёплый песочный. Знак «Дом-капля» остаётся в своих цветах (`#1C7C9C` и `#E9B23C`) и не перекрашивается вместе с интерфейсом.

| Роль                                       | Токен                  | Цвет      |
| ------------------------------------------ | ---------------------- | --------- |
| Основной (кнопки)                          | `--color-accent`       | `#2E7A68` |
| Ссылки и текст-акцент                      | `--color-accent-text`  | `#256656` |
| Мягкий фон акцента                         | `--color-accent-soft`  | `#E4F2EC` |
| Тёмный (заголовки, подвал)                 | `--color-ink`          | `#14302A` |
| Основной текст                             | `--color-text`         | `#17251F` |
| Второстепенный текст                       | `--color-muted`        | `#5A6B66` |
| Линии                                      | `--color-line`         | `#E1EBE6` |
| Фон карточек                               | `--color-surface-soft` | `#F2F7F4` |
| Капля, солнце (только знак и мелкие метки) | —                      | `#E9B23C` |
| Ошибка                                     | `--color-danger`       | `#B3374A` |

Статусы: «новое» `#245C99` на `#E7F0FA`, «в работе» `#8A5B00` на `#FFF3D6`, «готово» `#1F6B43` на `#E3F3EA`. Тёмная тема и режим высокого контраста — те же роли, свои значения в `src/shared/styles/tokens.css`.

## Контраст (WCAG AA: текст ≥ 4,5)

| Пара                          | Контраст |
| ----------------------------- | -------- |
| Текст на белом                | 15,9     |
| Второстепенный текст на белом | 5,6      |
| Ссылка на белом               | 6,7      |
| Белый текст на основном       | 5,1      |
| Тёмный текст на жёлтом        | 8,3      |
| Ошибка на белом               | 5,9      |
| Статусы                       | 5,3–6,0  |

**Нельзя:** белый текст на жёлтом (1,9) — жёлтый только для капли и декоративных меток.

Все значения цветов живут в токенах; в компонентах — только `var(--…)`. Проверку контраста держит тест `src/shared/styles/tokens.test.ts`.
