# Aqmola: тестовый портал услуг Акмолинской области

Тестовый фронт портала услуг для всей Акмолинской области (3 города и 17 районов), по образцу [astana.kz](https://astana.kz/ru). Языки: русский, казахский, английский. Для жителей, бизнеса и операторов.

**Все данные тестовые и вымышленные.** Нет настоящего входа, нет внешних интеграций, нет сервера и базы данных. Сайт не является государственным сервисом.

## Запуск

Нужны Node.js 24 (см. `.nvmrc`) и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте http://localhost:3000, язык выберется по настройкам браузера (`/ru`, `/kk`, `/en`).

Боевая сборка:

```bash
pnpm build
pnpm start
```

### Демо-вход

Страница `/ru/sign-in`: выберите «Войти как житель», «как бизнес» или «как оператор» (и тестовую организацию). Пароля нет. Сессия и заявки хранятся в `localStorage` вашего браузера и никуда не отправляются, поэтому оператор видит заявки только из того же браузера. Для пробы в кабинете оператора есть кнопка «Добавить тестовые заявки».

Статусы заявки: Подана → В работе → Исполнена или Отклонена. Назад статус не меняется.

### Вид сайта

Кнопка с полукругом в шапке: тема (как в системе, светлая, тёмная), высокий контраст, крупный шрифт. Настройки хранятся в браузере.

## Проверки

```bash
pnpm check       # формат, линтер, типы, unit-тесты, сборка
pnpm test:e2e    # сценарии в браузере (собирает сайт и запускает на порту 3100)
```

Первый раз для e2e: `pnpm exec playwright install chromium`.

## Устройство

- Next.js 16 (App Router, Cache Components), React 19, TypeScript strict, CSS Modules.
- Языки без пакета: `src/app/[lang]`, словари `src/shared/i18n/dictionaries/{ru,kk,en}.json`.
- Код по фичам: `src/features/<фича>/{domain,data,ui}`, общее в `src/shared`. Страницы берут данные только через репозитории (`getCatalogRepository`, `getContentRepository`): сейчас это заглушки с тестовыми данными, позже их заменит настоящее API.
- Цвета и размеры: `src/shared/styles/tokens.css`. Контраст пар цветов проверяет тест `tokens.test.ts` (светлая и тёмная темы, 4.5:1; высокий контраст, 7:1).

## Что важно знать

- Казахский перевод — черновик, его нужно вычитать носителю языка.
- Список районов и городов нужно сверить с официальным административным делением.
- Фото скопированы с Wikimedia Commons (CC BY-SA 4.0) и лежат в `public/photos/`: сайт не зависит от внешнего сервера. Авторы указаны на страницах и в `public/photos/CREDITS.md`. Перед запуском фото заменить своими или лицензированными.
- Описания мест и новости вымышлены, перед запуском их заменит проверенный текст.
- Официального логотипа нет: в шапке временный знак.
